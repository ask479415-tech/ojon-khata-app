# ওজন খাতা - Smart Weight OCR & Calculator

হাতে লেখা ওজনের তালিকা (1.5, 2, 3.5 কেজি বা ১.৫, ২, ৩.৫ কেজি) ক্যামেরা দিয়ে স্ক্যান করুন, সংখ্যা যাচাই ও সংশোধন করুন এবং স্বয়ংক্রিয়ভাবে মোট কেজি ও টাকার হিসাব করুন।

## প্রধান ফিচারসমূহ:
1. **ক্যামেরা ও গ্যালারি:** ক্যামেরা দিয়ে খাতা বা স্লিপের ছবি তোলা ও গ্যালারি থেকে আপলোড।
2. **হাতে লেখা OCR:** Gemini 3.8 Flash মডেল দিয়ে বাংলা ও ইংরেজি উভয় সংখ্যা নির্ভুলভাবে সনাক্তকরণ।
3. **যাচাই ও সংশোধন স্ক্রিন:** মূল ছবির সাথে মিলিয়ে ভুল সংখ্যা ঠিক করা ও বাদ পড়া সংখ্যা যোগ করা।
4. **স্বয়ংক্রিয় যোগফল:** মোট কেজি (Total KG), খালি বস্তা বাদ (Tare deduction) এবং দর অনুযায়ী মোট টাকা।
5. **চালান মেমো এক্সপোর্ট ও শেয়ার:** 
   - উচ্চ রেজুলেশনের মেমো ছবি (PNG) তৈরি ও ডাউনলোড।
   - হোয়াটসঅ্যাপে সরাসরি ছবি ও ফরম্যাটেড টেক্সট শেয়ার।
6. **ব্যবহারকারী প্রোফাইল ও লগইন:** একাধিক দোকান বা আড়তের নাম দিয়ে প্রোফাইল তৈরির সুবিধা।

## নিজের কম্পিউটারে যেভাবে চালাবেন (How to run locally):

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. এনভায়রনমেন্ট ভেরিয়েবল সেট করুন:
`.env.example` ফাইলটি কপি করে `.env` নাম দিন এবং আপনার Gemini API Key বসান:
```bash
GEMINI_API_KEY="আপনার_জেমিনি_এপিআই_কি"
```

### ৩. অ্যাপ রান করুন:
```bash
npm run dev
```

ব্রাউজারে খুলুন: `http://localhost:3000`
